Nectaris / Military Madness — SFX soundboard

All 36 effects are the original Nec.exe WAVE resources (8-bit mono 22050 Hz). Listen to each one, then assign the SE that belongs to every game event. Export the result and drop it into assets/data/audio.json — the runtime reads that file, so no rebuild is needed.

Provisional mapping. The IDs currently selected were guesses and are known to be wrong. Please correct them by ear.
